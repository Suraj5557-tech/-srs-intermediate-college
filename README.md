# SRS Intermediate College Website

This is the official frontend website for SRS Intermediate College, built with React and Vite.

## Tech Stack
* **Frontend:** React.js, Vite
* **Styling:** Tailwind CSS

## Run Locally
1. Clone the project:
   `git clone https://github.com/Suraj5557-tech/-srs-intermediate-college.git`
2. Install dependencies:
   `npm install`
3. Start dev server:
   `npm run dev`
